# Beginner glossary (plain English)

| Term | Meaning |
|------|---------|
| **ADLS Gen2** | Azure’s big file storage for data projects (folders of CSV/Parquet). |
| **Databricks** | Cloud workspace where we run PySpark notebooks to transform data. |
| **PySpark** | Python API for Spark — processes large tables in parallel. |
| **Bronze / Silver / Gold** | Raw → cleaned → business metrics layers (Medallion Architecture). |
| **ADF (Azure Data Factory)** | Scheduler that runs pipeline steps every day automatically. |
| **Streamlit** | Easy Python library to build a simple web dashboard. |
| **Docker** | Packages the app + dependencies into a portable “box” for hosting. |
| **Portfolio Pivot** | Switch the app from Azure to a local file so hosting stays free. |
